# Default Production Profile

Owner-editable starting point. The machine-readable defaults are in `config/production_profile.toml`.

| Setting | Default |
|---|---|
| Pilot | 60–90 seconds |
| Full documentary | 10–15 minutes |
| Frame | 16:9, 1920×1080, 24 fps |
| Language | British English |
| Narration | Warm male storyteller |
| Lead | Original expressive stick figure; blue top, blue/neutral trousers |
| Visual style | Hand-drawn 2D, illustrated worlds, diagrams and character action |
| Text | Short handwritten labels; no long text cards |
| Captions | Separate synchronized SRT |
| Photos | Off by default; only with clear purpose and verified rights |
| Music/SFX | Selective, free-to-use with documented licence |
| Budget | ₹0; no subscriptions, trials, paid credits or paid fallback |
| Approval | Owner approves script, major style changes, rights-sensitive assets and release |

Edit this file and the TOML profile to change defaults. Latest owner-approved changes override older settings.
