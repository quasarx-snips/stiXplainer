# stiXplainer Agent Team

## Eight specialists + one coordinator
1. Research Producer — evidence brief and source candidates.
2. Fact Checker — claim-to-source audit and safer wording.
3. Scriptwriter — timed British-English narration.
4. Story Architect — beat sheet and storyboard.
5. Visual Director — composition, palette, environments and transitions.
6. Character Designer — original reusable cast, expressions and poses.
7. Animation Engineer — scene implementation and rendering.
8. Audio, Editor & QC Producer — narration, licensed sound, subtitles, assembly and media inspection.

**Default coordinator:** stiXplainer Studio Director. It is an additional coordinator, not a ninth worker.

## Sequence
Brief → Research → Fact-check → Script → Storyboard → Visual Direction + Character Design (parallel) → Animation → Audio/Edit/QC → Studio Director review.

Each hand-off must state completed work, files changed, evidence, open issues and next hand-off. Research and fact-check precede script. Visual direction and character design can run in parallel after storyboard. Never confuse a plan, source file or workflow with a completed output.

## Human approval
The owner is creative director. Approval is required for material mascot/style changes, disputed factual interpretations, unclear asset rights, spending, and public release. Routine decisions within approved defaults should proceed without repeated questions.

## Runtime boundary
The files in `.github/agents/` are role profiles for compatible agent hosts. They are not eight live services and GitHub Actions does not run them. Actual delegation requires a compatible host with custom-agent/subagent support and model/runtime access. If unavailable, use the same roles sequentially and disclose that. No paid API key or paid runtime is configured.
